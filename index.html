The Darkside Detective ภาษาไทย

Season 1 ครบ 9 คดี · ทดสอบกับเวอร์ชัน Epic Games Store (Unity 2019.4.18f1)

ดาวน์โหลดมอด ไฟล์ zip มี 3 ไฟล์ พร้อมคู่มือ

วิธีลงมอด

  1. ปิดเกม แล้วเปิดโฟลเดอร์เกม
    Epic: Library → ... ที่เกม → Manage → กดไอคอนโฟลเดอร์
    Steam: คลิกขวาที่เกม → Manage → Browse local files
  2. สำรองไฟล์เดิม 3 ไฟล์ คัดลอกไปเก็บไว้ที่อื่น หรือเปลี่ยนชื่อโดยเติม .bak ต่อท้าย
  3. แตกไฟล์ zip แล้ววางทับ ตามตารางด้านล่าง ถ้า Windows ถาม ให้เลือก Replace the files in the destination
  4. เปิดเกม แล้วเลือกภาษา ไปที่ Options → Language แล้วเลือก ไทย (อยู่ในช่องที่เดิมเป็น 中文)
ไฟล์ในมอดวางไว้ที่
resources.assetsthedarksidedetective_Data\
sharedassets0.assetsthedarksidedetective_Data\
SpookyDoorway.DarksideShared.dllthedarksidedetective_Data\Managed\

ไฟล์ .dll ต้องอยู่ในโฟลเดอร์ Managed ไม่ใช่โฟลเดอร์เดียวกับอีกสองไฟล์

แปลอะไรไปบ้าง

  • บทพูดครบ 9 คดี ประมาณ 8,400 บรรทัด
  • ชื่อไอเทม จุดสำรวจในฉาก และเมนูทั้งหมด
  • ภาพชื่อคดี ปุ่ม จอปริศนา ป้าย และหนังสือพิมพ์ 78 ภาพ
  • ฟอนต์พิกเซล Silver ที่เติมอักษรไทยให้เข้ากับเกม
  • ชื่อร้าน ชื่อเฉพาะ และปกบางอันยังคงเป็นภาษาอังกฤษ

ถาม-ตอบ

จะถอดมอดออกยังไง

เอาไฟล์ที่สำรองไว้กลับไปวางทับ หรือกด Verify ให้ Launcher โหลดไฟล์เดิมคืน

Epic: Library → ... → Manage → Verify
Steam: Properties → Installed Files → Verify integrity of game files

เปิดเกมแล้วเด้ง หรือจอดำ

เวอร์ชันเกมอาจไม่ตรงกับมอด มอดทดสอบกับเวอร์ชัน Epic ส่วน Steam และ GOG ยังไม่ได้ทดสอบ ให้คืนไฟล์เดิมก่อน

ไม่มีภาษาไทยในเมนู

ตรวจว่าวาง resources.assets ในโฟลเดอร์ thedarksidedetective_Data และทับไฟล์เดิมแล้ว

สระลอย หรือตัวอักษรเป็นสี่เหลี่ยม

ยังไม่ได้วาง sharedassets0.assets ทับ ไฟล์นี้เก็บฟอนต์ของบทพูด

หน้าเริ่มเกมยังมีตัวจีน

ยังไม่ได้วางไฟล์ .dll ในโฟลเดอร์ Managed

อัปเดตเกมแล้วมอดหาย

Launcher อาจเขียนไฟล์ทับ ให้ลงมอดใหม่ ถ้าลงแล้วยังเด้ง แปลว่าเกมเปลี่ยนเวอร์ชัน ต้องรอมอดอัปเดต

มอดทั้งหมดในหน้านี้ทำโดยแฟน ไม่ใช่ของทางการ ต้องมีเกมแท้จึงจะใช้ได้ ลิขสิทธิ์เกมเป็นของผู้พัฒนาและผู้จัดจำหน่ายแต่ละเกม
